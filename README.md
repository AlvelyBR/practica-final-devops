# Practica Final DevOps

Este proyecto es una aplicación web sencilla "Hola Mundo" creada para demostrar un flujo completo de DevOps.

## Descripción

La aplicación muestra una página web con un mensaje básico. El proyecto incluye pruebas automáticas, está contenerizado con Docker y cuenta con un pipeline de integración y despliegue continuo utilizando GitHub Actions. Finalmente, la aplicación se publica en producción mediante Render.

## Tecnologías utilizadas

- Node.js con Express
- Jest para pruebas unitarias
- Docker
- GitHub Actions
- Docker Hub
- Render

## Ejecución local

Instalar dependencias:
npm install

Ejecutar la aplicación:
npm start

Abrir en el navegador:
http://localhost:3000

## Pruebas

Para ejecutar las pruebas:
npm test
